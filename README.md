# 📖 Overview

**JobSeek** is a modern full-stack Job Portal built using the **MERN Stack**.

The platform allows recruiters to create companies, post jobs, and manage applications, while job seekers can browse opportunities, apply for jobs, upload resumes, and track their applications.

The project follows a scalable architecture with secure authentication, cloud-based image storage, and responsive UI.

# 🚀 Installation

## 1 Clone Repository

```bash
git clone https://github.com/amanpatel-200/JobSeek.git
```

```
cd JobSeek
```

---

## 2 Install Backend

```bash
npm install
```

---

## 3 Install Frontend

```bash
cd fronted
npm install
```

---

## 4 Environment Variables

Create a **.env** file in the root directory.

```env
PORT=8000

MONGO_URI=Your MongoDB URL

JWT_SECRET=Your JWT Secret

CLOUDINARY_CLOUD_NAME=Your Cloud Name

CLOUDINARY_API_KEY=Your API Key

CLOUDINARY_API_SECRET=Your API Secret
```

---

## 5 Start Backend

```bash
npm run dev
```

---

## 6 Start Frontend

```bash
cd fronted

npm run dev
```
